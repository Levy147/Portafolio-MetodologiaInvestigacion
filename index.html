¿Cómo se actualiza este portafolio?

Un flujo simple, 100% estático y sin servidores.

01

Subo mis archivos

02

GitHub Pages despliega

03

El sitio lee la carpeta

La web consulta la carpeta archivos/ vía la API de GitHub y lista los documentos al instante.
